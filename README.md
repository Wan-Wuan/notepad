# 笔记软件 v1.5

一个基于 Electron + React + TypeScript 的个人本地笔记软件。

## 功能特性

### 核心功能
- **富文本编辑** - 支持标题、粗体、斜体、高亮、代码块等
- **笔记管理** - 创建、删除、拖动排序
- **笔记分类** - 支持自定义分类，拖动笔记到分类
- **本地存储** - 数据存储在本地文件系统
- **搜索功能** - 支持标题和内容搜索
- **大纲显示** - 自动提取标题生成大纲，支持折叠/展开
- **面板调整** - 可拖拽调整侧边栏和大纲面板宽度

### 编辑功能

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 标题 | H1/H2/H3 | 插入不同级别标题 |
| 粗体 | Ctrl+B | 加粗选中文本 |
| 斜体 | Ctrl+I | 倾斜选中文本 |
| 高亮 | - | 高亮选中文本 |
| 行内代码 | - | 插入行内代码 |
| 代码块 | - | 插入多行代码块 |
| 无序列表 | - | 创建无序列表 |
| 有序列表 | - | 创建有序列表 |
| 任务列表 | - | 创建任务列表 |
| 引用 | - | 插入引用块 |
| 链接 | - | 插入超链接 |
| 分割线 | - | 插入分割线 |

### 分类管理

| 功能 | 说明 |
|------|------|
| 默认分类 | 默认、工作、学习、生活、想法 |
| 自定义分类 | 点击"+"按钮添加新分类 |
| 重命名分类 | 点击编辑图标重命名 |
| 删除分类 | 点击删除图标删除（默认分类不可删） |
| 拖动到分类 | 将笔记拖动到分类项上更改分类 |
| 分类筛选 | 点击分类筛选对应笔记 |

### 其他功能

| 功能 | 说明 |
|------|------|
| 删除确认 | 删除笔记前显示确认对话框，防止误删 |
| 大纲显示 | 右侧显示笔记大纲，点击可跳转到对应位置 |
| 大纲折叠 | 支持单个标题折叠/展开，以及全部折叠/展开 |
| 大纲隐藏 | 工具栏可切换大纲显示/隐藏状态 |
| 字数统计 | 底部状态栏显示字符数和词数 |
| 导出Markdown | 将笔记导出为.md文件 |
| 复制内容 | 一键复制笔记纯文本内容 |
| 拖动排序 | 拖动笔记调整顺序 |
| 面板调整 | 拖拽边缘调整侧边栏和大纲宽度 |
| 快捷键 | Ctrl+N 新建笔记 |
| 状态保存 | 大纲显示状态和面板宽度保存到本地存储 |

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 打包安装包

```bash
npm run dist:win
```

## 项目结构

```
notepad/
├── electron/              # Electron 主进程
│   ├── main/             # 主进程入口
│   └── preload/          # 预加载脚本
├── src/                  # React 前端
│   ├── App.tsx           # 主应用组件
│   └── main.tsx          # 入口文件
├── resources/            # 资源文件
```

## 数据存储

笔记数据存储在本地文件系统：

| 系统 | 路径 |
|------|------|
| Windows | `%APPDATA%/notepad/notes/` |
| macOS | `~/Library/Application Support/notepad/notes/` |
| Linux | `~/.config/notepad/notes/` |

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + N` | 新建笔记 |
| `Ctrl + B` | 粗体 |
| `Ctrl + I` | 斜体 |
